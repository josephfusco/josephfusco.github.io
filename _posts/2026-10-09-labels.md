I'm moving the repositories I maintain to the label set I use on [WordPress/presence-api](https://github.com/WordPress/presence-api/labels). Voiceboard has it so far. For each one, I give an agent the hex values on this page and tell it to set up the same system, changing what the project needs.

A label's hue says what kind of label it is. Labels in a family share one color: every `[Area]` label is the same yellow, and the name says which area. The issue types get four colors, because an issue has one type and I sort by it.

Saturation says how hard a label pulls. Most labels are pale, the colors of sticky notes, so they can be read without drawing attention. Two colors are strong, and they are for issues someone has to act on. The labels that bots and releases apply are close to gray.

## How much each one pulls

Chroma measures that pull: how far a color sits from gray, on a scale of 0 to 100. Sorted by chroma, the set falls into three tiers.

<ul class="chroma-tiers">
  <li><span class="tier">Act on it</span><span class="swatches"><span class="swatch" style="--c:#DC3545" title="#DC3545"></span><span class="swatch" style="--c:#F2994A" title="#F2994A"></span></span><span class="chroma">65-66</span></li>
  <li><span class="tier">Read it</span><span class="swatches"><span class="swatch" style="--c:#FEF298" title="#FEF298"></span><span class="swatch" style="--c:#97EDA0" title="#97EDA0"></span><span class="swatch" style="--c:#FFB7B0" title="#FFB7B0"></span><span class="swatch" style="--c:#B5E0FF" title="#B5E0FF"></span><span class="swatch" style="--c:#E2C8FF" title="#E2C8FF"></span><span class="swatch" style="--c:#B8EAE0" title="#B8EAE0"></span><span class="swatch" style="--c:#DED6B0" title="#DED6B0"></span></span><span class="chroma">18-40</span></li>

`#DC3545` is also the darkest color in the set, so it is the first thing you see on a list of issues.

## Handing it to an agent

What I say:

> Set up labels on this repository using the same label system and hex values as WordPress/presence-api. Keep the families and colors. Replace the [Area] labels with this project's own areas, all #FEF298.
